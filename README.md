# Store Management Database

A relational database project built with MySQL to manage customers, 
products, employees, and store transactions.

## Features

- Customer management
- Product management
- Employee management
- Transaction management
- Primary keys
- Foreign keys
- Constraints
- CRUD operations
- Transactions
- Views
- Aggregate functions
- GROUP BY
- HAVING
- JOINs
- Subqueries
- ORDER BY

## Database Structure

The database contains four main tables:

- `customers`
- `products`
- `employees`
- `transactions`

## Technologies

- MySQL
- SQL
- MySQL Workbench

## What I Learned

This project was created while learning MySQL and SQL. It demonstrates
database creation, table relationships, data manipulation, constraints,
queries, and data analysis.
